# Macroinvertebrate Image Analysis System

## Project Overview
This project analyses freshwater macroinvertebrate image data using Python. The system performs exploratory data analysis (EDA), visualisation, and graphical user interaction to help users explore the dataset.

## Features
- Dataset loading and analysis
- Class distribution visualisations
- Sample image viewing
- Image statistics and summaries
- Desktop GUI interface using Tkinter

## How to Run
1. Install requirements:
```bash
pip install -r requirements.txt
```

2. Run the project:
```bash
python main.py
```
